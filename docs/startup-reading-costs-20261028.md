# 启动缓存、连续阅读与费用估算

实现边界：不使用 Computer Use，不生成便携包；在已有安装中更新 DLL，保留配置、明文密钥及既有课堂记录。没有新增音频落盘功能。

## 启动

MainWindow 在等待 ASR StartAsync 之前启动实际音频服务，数据直接进入有界内存队列。ASR 只在 task-started 后开始发送。启动缓存上限 640000 字节（单声道 16k/16bit，20 秒）；积压降低到 5 秒后恢复 160000 字节上限，保持原有重连边界。连接中状态明确表示已收音待补发。停止未完成的握手时取消底层任务，清空并擦除未发送数组。

## 阅读

CaptionPageComposer 以连续双语片段为单位积累页面，使用 WPF 排版测量判断是否溢出。页面未满时继续添加；有下一段且放不下、已显示至少 3 秒时换页。ASR 预览只填当前页余量，不显示快速滑动的末尾词条。主窗口与悬浮窗口分别按各自空间排版。ASR 改写页首时通过前一片段定位，避免跳回历史开头。超长单段通过滚动容器查看；显示分页不删除保存记录或改变翻译调度。

## 用量与估算

ASR 协议从普通结果、心跳和 task-finished 中读取累计用量；每个连接 ID 单独去重累计，重连后的连接独立记账。LLM 在校验译文前报告真实 usage，缓存命中与未命中分别计价；格式错误或后续 ASR 作废不抹掉已发生的模型用量。未回报的请求保留待回报状态。未知模型或未知地域未配单价时不擅自套用已知价格。

截至 2026-10-28 的官方参考价，单位人民币/百万 token：
- ASR 北京输入 6、输出 4.5；新加坡输入 6.781、输出 5.104。
- DeepSeek Flash 高峰缓存命中 0.04、未命中 2、输出 8；空闲分别 0.02、1、4。
- 自动时段为北京时间周一至周五 9:00–12:00、14:00–18:00；没有内置节假日数据，提供高峰/空闲手动选择。以厂商实际账单为准，未扣免费额度或优惠。
- 每次课堂冻结当时模型和价格配置。用量与估算结果写入 JSONL usage 事件；无密钥、请求头或音频。

来源：https://help.aliyun.com/zh/model-studio/model-pricing 和 https://api-docs.deepseek.com/zh-cn/quick_start/pricing/ 。

验证：模拟慢握手中排队 6 秒音频，确认握手前不发送且启动后顺序不变；握手中取消及时清空。验证分段累积、满页换页、页首修订、费用去重、时段/地域/自定义价、未知用量及无效译文仍计入 usage。界面使用自有 WPF 控件离屏渲染检查小窗口、双语积累和费用行。显式真实接口诊断发送两条内置俄语短句，不采集或发送课堂录音；返回 usage 并得出非零估算。上述检查不代表教室现场验收或账单精确对账。
