1.1 版验证边界

2026-10-27 本地检查：52 项核心测试、10 项 Windows 窗口组件及离屏渲染检查。
每项测试结果随包附在“自动验证结果.json”和“窗口组件验证结果.json”。
三种模式均经过模拟 90 分钟课堂，不代表已实录运行 90 分钟。
新版验收采用构建、组件测试与程序自身的离屏渲染；离屏预览不截取桌面、不发送桌面输入。
根据用户要求，后续验收不使用 Computer Use。物理鼠标手感、投影效果和动画流畅度仍需人工实机体验。

已覆盖的自动检查：
密钥加密、错误密码、密文篡改、密码更换和复制密钥库后的解锁。
官方域名与 HTTPS/WSS 限制、错误响应脱敏。
ASR 部分结果、最终结果和心跳解析；固定俄语 PCM 请求。
ASR 回改、旧译文晚到、分段遗漏和重叠拒绝。
单请求调度、无新增内容不重复调用、重试退避和三模式差异。
长语音跨请求窗口、模拟 90 分钟课堂、有限历史与录音缓存。
文字记录导出与目录写入失败。
断线前未完成片段暂存，重连后不阻塞新字幕确认。
保存目录不可读取时明确标记并导出内存中的近期记录。
公共 ASR 入口无需 Workspace ID；指定业务空间或官方完整地址仍可使用。
API Key 输入位于常规设置首屏，地址和模型参数默认折叠，历史记录默认收起。
录音列表区分可用、已禁用和未连接设备，非可用设备不允许用于收音。默认构建不生成便携包。

真实模型和现场验收：
真实 API 密钥未预置。需在软件中自行配置和完成连接测试。
真实外教音频的识别准确率、俄译中质量、实际延迟及费用尚待实测。
教室电脑兼容性、多显示器投影、麦克风收音和拔出设备恢复需现场验证。
自动化模拟和本机检查不能替代上述验收。
