# 课堂字幕：连续阅读与改译过渡

设计目标是让人继续读下去。动画解释文字如何变化，不要求用户重新读一遍刚才的整句。

[Figma 可编辑页面与过渡状态](https://www.figma.com/design/JWKE3YEnhR1q4m6AwE0kJ0?node-id=5-9)包含主窗口、半透明字幕和改译状态，全部由可编辑文本、矢量、布局及组件构成，没有整页截图充当设计稿。Windows 控件使用平台字体；Figma 用可用的 Noto Sans SC 表达中文与版式，WPF 为实际实现依据。

## 中文变化分类

| 变化 | 例子 | 显示规则 |
|---|---|---|
| 初次显示、尾部续写 | 船舶稳定。→ 船舶稳定。货物安全。 | 已显示部分不动，仅新字符依积压量加速出现；按积压量在中文每秒10–26字素、俄文每秒18–42字素之间调整，取消半秒内排完的限制，进入动画220ms；改译中的新字也逐字排程，相同待显示文字保留原排程 |
| 中间补字 | 船舶稳定。→ 船舶非常稳定。 | 相同字保持可见，新字淡入，邻字平移让位 |
| 删除短语 | 船舶非常稳定。→ 船舶稳定。 | 被删部分约220ms淡出，保留字同步收拢 |
| 局部替换 | 需要调整→必须调整 | 先用不变文字界定改动区间，旧词与新词同时交叉过渡；禁止从其他行的删除位置借用起点 |
| 大幅调整语序 | 船舶稳定，货物安全。→ 货物安全，船舶稳定。 | 作为连贯的文本块交叉淡化，避免相同单字穿过整段文字 |
| 整句重译 | 今天天气晴朗。→ 重心升高会降低初稳性。 | 新旧版本约220ms同步交叉淡化，不清空、不逐字重播整句 |
| 等待新译文 | A→空值或已译前缀→B | 等待期间保持A；B就绪才做差异过渡，临时前缀不当成真正删除 |
| 过渡中再次修订 | A→B尚未结束→C | 以当前屏幕姿态接续C，取消尚未显示的过时字符，不倒回A、不强制播完B |

分析使用字素而非UTF-16单元，组合字符与emoji不被切开。共同字形按前后缀和有界LCS匹配；相似度低于38%按整句处理。若字符集合重合度高于90%、顺序匹配低于78%，按大幅语序变化处理。这是确定性的显示启发式，不宣称理解句子语义。

## 连续滚动

- 主窗口与悬浮字幕均使用独立的俄文、中文阅读范围，不再触发旧的整页换页。
- 顶部将离开的旧行在原位置约180ms渐隐；保留行延后100ms开始、约280ms平滑上移，新行从底部接续，避免裁成半截字后才消失。
- 底色跟随相同的行过渡，透明度保持用户设置；命中测试排除范围外和不可见底色，保留“只拖底色块移动”的交互。
- 悬浮字幕显示范围铺满当前屏幕宽度，俄文、中文各保留三行；高度按各自字号和行高计算。中俄块之间约6 DIP可见间距。多行底色覆盖完整行高并连接，行形状先合成、整组再应用用户透明度，避免行间空隙及重复叠加的深色接缝。
- 显示层处理最近12个片段，主窗口以俄文600字素、中文400字素为预算；悬浮字幕随屏幕宽度和字号增加预算，为三行及过渡保留足够文字，上限俄文6000、中文4000字素。片段边界与服务返回的硬换行不参与排版，中俄文均尽量填满横向空间后自然折行；完整原文、译文及本地记录不被裁剪。
- 每次更新布局一次，后续帧只修改保留图层的位置、透明度和底色几何；字形图像缓存上限1024项。字幕逐字显示独立于系统动画开关。
- 视口外的字形移出绘制场景，仅在将进入范围时重新挂回；缓冲长度增加不会让所有旧字都参与每帧合成。

## 页面精修

沿用深蓝灰与海玻璃绿，控制栏收至184 DIP、与字幕区统一深度，扩大阅读宽度。原文18/29、译文32/49，使用留白区分两种语言，删除无效节奏标题和阅读区技术用量行；费用与用量保留在记录的明细中。

## 验证与边界

`tests/ClassroomCaption.WindowsTests/CaptionMotionPreview.cs`用实际WPF字幕组件生成8秒合成文本录样，覆盖局部替换、等待前缀、溢出滚动、整句重译和中途修订。输出为`artifacts/ui-redesign/caption-motion.mp4`与GIF；240帧、每秒30帧是录样参数，不是实际桌面显示帧率测量。

自动检查包含变化分类、替换区间、无整帧空白、保留字形、动画中断、滚动范围、字素边界和透明命中。逐帧检查了顶部残字与跨行飞字，并修正其原因。未用桌面自动操作工具做真实课堂或鼠标验收；真实语音的时延和译文质量也不由这组显示测试证明。

相同的WPF离屏滚动压力用例（120/360/720字）在裁去不可见字形前后，帧耗时中位数约从11.5/16.1/19.4ms降至8.0/8.0/10.4ms；改译布局约2ms。原始结果在`artifacts/caption-flow-before.json`和`artifacts/caption-flow-after.json`。这是组件CPU与离屏合成测量，不是桌面帧率或真实课堂测试。



## 字幕与悬浮球的连续转场

双击字幕暂停，双击球继续；取消字幕和球的右键菜单。拖动球必须超过系统拖动阈值，单击不启动、不贴边，避免影响双击。

使用位置和尺寸固定的独立转场层，交互球窗口始终48 DIP。单一线性进度经过五次平滑函数，连续控制画面中心、等比例缩放、球形轮廓、透明度与滚动角度；展开逆向走同一曲线。可见原生窗口不在动画中改宽高或位置。两端的原画面与球在相同坐标和像素形状接续。

收起缓存的是当时的俄文与中文实际渲染画面，冻结文字与逐字动画。展开不重新抓取空字幕，而是使用原缓存；接续完成后恢复字形动画，新识别和翻译追加在旧内容之后。同一份本地课堂记录和累计时长保留，演示游标保留。正式同传重连使用新的服务端会话，但本地标识与版本持续递增，不覆盖旧记录。

`--floating-tests`检查双击原生消息、取消右键、固定窗口边界、转场边界连续性、缓存文字恢复、演示续播和动画取消；还生成121帧实际WPF离屏预览，路径为`artifacts/continuous-morph/frame-000.png`至`frame-120.png`。离屏动画与消息检查不等于真实鼠标、投影设备或在线同传验收。

教室兼容性：字幕逐字呈现与字幕球变换不读取系统 ClientAreaAnimation 开关。专项检查仅在隔离测试进程中将 WPF 缓存设为关闭，验证正式翻译、演示和球转场仍执行动画，不修改注册表或 Windows 设置。
