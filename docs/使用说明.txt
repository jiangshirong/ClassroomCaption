课堂字幕 Windows 当前开发版

1. 在模型设置中填写阿里云 API Key、对应地域和 Workspace ID。
2. 船舶摇荡课程术语已内置，课堂设置不再显示大段术语表。
   已有自定义术语配置仍会保留；内置术语在连接时自动加载。
3. 选择麦克风，点击开始翻译。原文和译文来自同一个 LiveTranslate 会话。
   麦克风显示精简名称，悬停可查看完整名称；同名设备会补充区分信息。
   麦克风下方“本地降噪”可随时开关，默认关闭，重启后保留选择。
   “更多 → 试听”也使用此选择，可分别试听原始与降噪效果；试听期间暂不能切换。
   音量条与音量过大提示显示降噪前的输入。降噪不删除静音，不需要虚拟声卡。
4. 结束课堂后等待同传收尾。连接短暂中断时保留字幕并自动恢复，逐步延长等待，连续失败最多重试6次。
   恢复期间保留最近约20秒尚未发送的音频，超出部分明确记录缺口；已发送的音频不自动重传。
   点击结束课堂会取消恢复。密钥、权限等配置错误不反复重试。
   未联网时点击开始翻译，直接提示“未联网”，不开始收音或创建课堂记录。
5. 只保存文字，不保存音频。密钥按用户选择明文保存在本机。
   点击「悬浮字幕」切换显示或隐藏，按钮高亮表示字幕已显示。
   主窗口为紧凑控制面板；「记录」开启时按钮高亮并按需展开记录区，关闭后恢复原尺寸和位置。长句自动换行；实时字幕只在悬浮字幕中显示。
6. 厂商返回的音频输入和中文译文输出 token 分别保存在课堂 JSONL 记录中，不估算俄语原文 token。
7. 优先使用 E:\课堂字幕\data；没有E盘时使用 D:\课堂字幕\data，包含设置、密钥、课堂文字和检测报告。
   自动复制旧默认目录及软件旁旧 data 中的记录，原文件保留，已有新配置不覆盖。
   E、D盘均不存在或选定目录不可写时会提示选择目录，不静默改存C盘。首次迁移后仍可在课堂设置中修改文字保存位置。

旧发布包不会自动升级；教室现场兼容性与真实收音、识别、翻译效果仍需实测。

悬浮字幕外观：更多 → 字幕外观，可选黑底白字或白底黑字。
托盘图标右键提供「开始翻译 / 停止翻译」，直接控制翻译和字幕，不打开主窗口；双击托盘图标仍可打开主窗口。
软件打开后即在当前屏幕右侧显示字幕球，不自动录音。双击球开始；托盘或主窗口停止翻译后，字幕收回球，球会保留到退出软件。
双击字幕文字底色，会暂停翻译、关闭麦克风采集，字幕连续收拢成悬浮球并滚动到屏幕边缘。悬浮球可拖动，松开后吸附左右边缘；双击球会从上次收起时的俄文、中文画面连续展开，保留同一份课堂记录，并在旧内容后继续翻译。演示也会从原来的播放位置继续。字幕与球均不再提供右键菜单；托盘右键启停仍保留。字幕逐字显示、收拢与展开动画独立于 Windows 的系统动画开关。正式翻译需要网络、麦克风和连接配置可用；恢复失败时回到悬浮球，保留原文字。
字幕范围自动扩展到当前屏幕左右边界，俄文、中文各最多三行，两种语言间距已缩小。各语言的多行底色连续连接，透明度统一合成，避免重叠黑线；短行仍随文字收紧。只能拖动文字底色块移动字幕，水平方向贴合屏幕，竖直位置可调整；外围透明范围可操作下方课件。达到显示范围后，顶部旧行渐隐，其余行平滑上移，新内容接续显示。完整文字可在“记录”中查看。此模式不读取屏幕背景。
“底色透明度”默认25%，可调0%至100%，数值越高越透明；文字保持不透明。100%时隐藏底色，不再作为拖动目标。设置即时生效并保存在本机，重启后保留。
改译时保留相同文字，只过渡变化的部分；整句重译会交叉淡化。等待新版本时继续保留旧译文，连续修订也不会先清空再逐字重播。
公式采用原生 LaTeX 排版：明确的 x/y、x除以y 等显示为上下分数；支持上下标、根号、三角函数和显式 LaTeX。只统一明确的符号与运算结构，不自动补全听不清的公式。原始文字记录保持原样，显示正确不代表识别出的数学内容必然正确。

账单查询页面已移除。字幕默认允许拖动，无需恢复操作。
