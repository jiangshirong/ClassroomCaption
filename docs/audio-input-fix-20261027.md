# 收音静音排查与修复

- 用户报告：Windows 输入音量条能跳动；软件音量条无跳动，试听回放无声。
- 更新核对：两个现有安装目录的应用 DLL 与开发输出哈希相同。
- 运行记录：最近一次发送约 8.07 秒音频，峰值 RMS 为零，识别更新为零。
- 内存对比：同一麦克风、同一进程、相同时段，系统端点峰值约 0.15；普通 WASAPI 原始格式采集 RMS 约 6.2e-9，WinMM RMS 约 1.5e-5；RAW/Speech 流 RMS 约 0.073。端点和本进程音频会话均未静音、音量为 1。
- 结论：静音出现在普通音频处理路径；未确定具体的驱动或音效组件，未修改 Windows 设置。
- 修改：通过 IAudioClient2 为本程序的收音流请求 RAW/Speech，按设备原始格式读取，软件内重采样。若设置属性或初始化返回不支持，则回退同一设备的标准共享流。音频 COM 对象在同一个 MTA 工作线程创建、读取和释放。
- 实际主程序收音服务检查：采集 5 秒，输出约 5.01 秒 16 kHz 单声道 PCM，峰值 RMS 0.03818，无采集错误。仅统计音量和字节数，不保存录音，不上传或调用模型。
- 自动组件检查：14/14 通过。没有使用 Computer Use，没有生成便携包。已更新两个现有安装目录的应用 DLL，配置、密钥及课堂文字未改动。
- 边界：已测到实际收音信号；用户侧试听回放与完整俄语识别、翻译仍需后续实际确认。

复查入口：WindowsTests 的 --compare-microphones 对比接口，--probe-capture 使用实际主程序收音服务；这些选项会短时打开麦克风，只应在明确的收音排查中运行，普通组件检查不会打开麦克风。
